# Приёмка этапа 2 — игра без клавиатуры и мыши

Условие этапа из плана: «можно играть без клавиатуры и мыши: бой, квесты, торговцы, почта, групповая игра».
Здесь — что подготовить, что пройти в шлеме и как записать результат. Клавиатура лежит рядом только на случай,
если что-то не получится: каждое её использование — замечание.

## Подготовка

1. Сервер запускает пользователь: `mysqld.bat` → подождать → `worldserver.exe` и `authserver.exe`.
2. Клиент: `run-vr.cmd` (HD-данные — `run-vr.cmd hd`) из `C:\SharedMyProjects\WorldOfWarcraftVR`.
   Лог — `logs\wowee-vr-<дата>-<время>.log`, его можно отдать на разбор.
3. Персонаж: Lisa (Тельдрассил, лёгкая сцена) — для боя и заданий; Liska (Штормград) — для торговцев, почты,
   банка и полётов.
4. **Деньги персонажу** — командой в окне `worldserver.exe` (консоль сервера, права GM на аккаунте не нужны):

   ```
   .send money Lisa "Деньги" "Для приёмки" 1000000
   ```

   Сумма — в медных монетах: 1 000 000 = 100 золотых. Деньги приходят письмом — забрать в почтовом ящике
   (это же сценарий 7). Имя персонажа — как в игре, с заглавной буквы.

   В самой игре то же делает `.modify money 1000000` (деньги выбранному игроку или себе), но для неё нужен
   уровень GM на аккаунте (`.account set gmlevel gamer 3 -1` в консоли сервера — это изменение базы, решать
   пользователю) и ввод текста в чат, а его в VR пока нет.

5. **Маунт** (для сценария 9) — тоже в консоли `worldserver.exe`, персонаж может быть в игре:

   ```
   .player learn Lisa 33388
   .player learn Lisa 10793
   ```

   33388 — верховая езда (ученик), 10793 — полосатый ночной саблезуб (подойдёт и 458 — гнедая лошадь).
   Заклинание маунта появится в книге на вкладке «Общее» (или «Транспорт»): перетащить его на панель действий.
   Верховая езда в 3.3.5 — с 20 уровня; если персонаж ниже и маунт не вызывается — `.character level Lisa 20`
   (меняет персонажа в базе — решать пользователю).

6. **Бот для группы** (для сценария 10). Модуль playerbots на сервере есть, случайные боты выключены, поэтому
   бот — второй персонаж того же аккаунта. Войти Lisa и один раз набрать в чате **клавиатурой** (это подготовка,
   не замечание):

   ```
   .playerbots bot add Liska
   ```

   Liska появится рядом и будет ходить за Lisa; обычно бот сам вступает в группу. Убрать бота —
   `.playerbots bot remove Liska` или выход из игры. Если команда не сработала — текст ответа в чате записать.

## Кнопки (по умолчанию, для правши)

| Кнопка | Что делает | С левым хватом (модификатор) |
|---|---|---|
| Левый стик | ходьба вперёд-назад, шаг вбок | |
| Правый стик | поворот (рывком 45° или плавно) | |
| Правый курок | левая кнопка мыши по лучу: выбрать, нажать, перетащить | |
| Правый хват | правая кнопка мыши по лучу: говорить, атаковать, использовать предмет; на кнопке панели — рамка; у плеча или бедра — оружие | |
| Левый курок | заклинание в светящейся рамке (отпустить раньше — отмена каста) | кнопка 7 |
| A | прыжок | кнопка 3 |
| B | кнопка 2 | кнопка 4 |
| X | ближайший враг | кнопка 5 |
| Y | действие с целью (говорить, атаковать, подобрать) | кнопка 6 |
| Нажатие левого стика | автобег | |
| Нажатие правого стика | вернуть вид по центру | |
| Меню | Esc, игровое меню | |

Левое запястье — панель действий, цель и листание страниц; правое — микроменю (персонаж, книга, таланты,
задания, карта…) и сумки. Нажимаются второй рукой: лучом или кончиком пальца. Переназначить — Esc →
Интерфейс → WoWee → VR buttons.

## Сценарии

Каждый сценарий — с результатом «да» / «нет» / «с трудом». Отметить, понадобились ли клавиатура или мышь.

### 1. Вход в игру
- Экран входа и выбора персонажа: войти и выбрать персонажа лучом (сохранённый вход).
- Ожидается: в мир без клавиатуры.

### 2. Движение и комфорт
- Пройти, повернуть, прыгнуть, автобег, вернуть вид по центру, посмотреть вниз на тело.
- Подняться по склону, зайти в дом и выйти.
- Ожидается: без укачивания, тело и руки на месте.

### 3. Бой
- Выбрать врага кнопкой X и лучом (курок по врагу).
- Атаковать правым хватом по врагу или кнопкой Y; убедиться, что оружие достаётся само.
- Заклинания: перенести рамку хватом на кнопку, выстрелить левым курком; отменить каст ранним отпусканием.
- Наземное заклинание (если есть у класса) — точка по лучу.
- Достать и убрать оружие жестом вне боя.
- Ожидается: бой до победы без клавиатуры.

### 4. Добыча
- Обыскать труп (правый хват по нему), забрать всё и по одному предмету.
- Собрать траву или руду, если есть профессия; поднять предмет задания с земли.

### 5. Задания
- Взять задание у NPC: правый хват по нему, принять кнопкой в окне.
- Открыть журнал заданий с правого запястья, прочитать, отследить.
- Выполнить и сдать, выбрать награду.

### 6. Торговец и ремонт
- Купить предмет (правый хват по товару, покупка нескольких — окно количества).
- Продать предмет из сумки (правый хват по нему, пока открыт торговец).
- Выкупить проданное обратно, починить снаряжение.

### 7. Почта
- Подойти к почтовому ящику, открыть, забрать письмо с деньгами (см. «Подготовка»).
- Отправка письма требует имени и текста — это этап 3 (ввод текста); здесь только проверить, что окно открывается.

### 8. Сумки, книга, снаряжение
- Открыть книгу заклинаний и сумки (окна у руки), перетащить заклинание на панель действий.
- Надеть предмет из сумки (правый хват по нему), переложить предмет между сумками.
- Окно персонажа: снять и надеть вещь.

### 9. Перемещения
- **Распорядитель полётов.** Где он — спросить у стражника: правый хват по стражнику → в разговоре
  «Распорядитель полётов» → точка на карте и миникарте. У Lisa (Тельдрассил) ближайший — гиппогриф в
  Рут'теран (деревня внизу у моря; из Дарнаса туда ведёт портал), у Liska (Штормград) — грифон в городе.
  Правый хват по распорядителю → карта полётов → курок по точке → полёт. На карте только известные персонажу точки:
  если кроме своей нет ни одной, лететь некуда — отметить и пропустить.
- **Маунт** (см. «Подготовка», п. 5): сесть кнопкой панели действий, проехать, слезть повторным нажатием.
  Верхом правый хват у бедра и за плечом не достаёт оружие.

### 10. Группа
Нужен бот (см. «Подготовка», п. 6).
1. Если бот уже в группе — его портрет слева на большой панели. Выйти из группы: правый хват по своему
   портрету (большая панель, слева вверху) → в меню курком «Покинуть группу». Портрет бота пропадает.
2. Выбрать бота: курок по нему в мире. Его портрет — цель на левом запястье.
3. Пригласить: правый хват по портрету цели на запястье (или на большой панели) → меню → курком «Пригласить».
   Бот принимает сам, его портрет снова слева.
4. Меню портрета бота в группе: правый хват по портрету → видно пункты («Шепнуть», «Исключить»…); закрыть
   меню курком мимо него или кнопкой «Меню».
5. Бот ходит следом и помогает в бою: убить вдвоём одного моба, проверить, что добыча делится.
6. Принять приглашение от другого игрока бот не пришлёт; всплывающее окно приглашения проверить, когда будет
   второй живой игрок. Команды ботам — через чат, это этап 3.
- Записать, на каком шаге не вышло и что было на экране.

### 11. Смерть
- Погибнуть, отпустить дух кнопкой, дойти до тела, воскреснуть (или у духа-целителя).

### 12. Настройки и выход
- Esc (кнопка «Меню») → настройки: поменять одну VR-настройку, закрыть.
- Выйти из игры через меню.

### 13. Наблюдения
- Где падали кадры/с (дрожание, рывки), где неудобно или мелко, что пришлось делать клавиатурой.

## Известные ограничения (не считаются провалом этапа 2)

- Ввод текста — чат, письма, имена, макросы, команды ботам: этап 3.
- Правый клик по чужому питомцу WoWee считает атакой (ошибка upstream, в `stage-log.md`, пункт 10).
- На маунте тело и руки играют обычную анимацию.
- Производительность: цель — устойчивые 45 кадров/с с перепроецированием; в Штормграде клиент упирается в одно ядро.

## Как записать результат

Список номеров с отметкой, например: «3 — да; 6 — продажа с трудом, хват не попадает по мелкой кнопке;
10 — нет: меню портрета не открылось». По этому списку составляются задачи, итог — в `stage-log.md`.
